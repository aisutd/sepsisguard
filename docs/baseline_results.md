The tuned XGBoost baseline scores AUROC 0.808 and AUPRC 0.095 on the test set (8,067 patients, 308,780 hourly rows), where a random model would score an AUPRC of 0.018, since only 1.8% of hourly rows are labeled septic. Adding scale_pos_weight (≈55, the ratio of non-septic to septic rows) did not improve ranking, as AUROC and AUPRC dropped slightly (0.815→0.786, 0.091→0.086), but it shifted the predicted probabilities upward, so at a 0.5 threshold the share of septic hours caught rose from 2% to 47%, at the cost of alerts rising from 633 to about 35,000. A 50-trial Optuna search, scored on a separate validation set of training patients, raised AUPRC from 0.091 to 0.095 and chose a small model (depth 3, 21 trees) with a milder scale_pos_weight of about 9.6, which suggests extra model complexity mostly overfits on this data. With the tuned model, a 0.5 threshold fires 6,941 alerts and catches 19% of septic hours, so the alert threshold will need to be chosen carefully for real use.
