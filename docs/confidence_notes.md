I label a patient-hour row "high" confidence if under 10% of the 35 model input fields are missing, "low" if over 40% are missing, and "medium" in between, since a prediction built mostly on missing inputs is closer to a guess and shouldn't be shown with the same weight as one built on complete data. When testing on mock rows, I found that a row with every vital sign but no lab results that hour scores as "low", because labs make up 23 of the 35 fields and are usually only drawn every few hours. Once I know whether Maritza's cleaned data is forward-filled, I plan to tune these thresholds on the real data, or weigh missing vitals more heavily than missing labs.
