I chose DistilBART because it preserved details more consistently in my earlier comparison. The pipeline ranks features by absolute score and turns the top three into readable source text without interpreting the scores as patient measurements or reporting their direction. Across four mock inputs, the final summaries retained the selected feature names, but the model mostly copied the source and sometimes omitted its caveat about diagnosis. Postprocessing removes extra spaces and keeps up to two complete sentences, while a feature-name check catches omissions but does not fully verify factual accuracy.

## Week 3: verification (Issue #26)

I switched the default generator from DistilBART to a fixed template that fills in each patient's top SHAP features grouped by whether they raised or lowered the predicted risk. Every word comes from the input or from text we wrote, so it cannot invent a reason, and DistilBART is kept only as an optional backend whose output must pass verification or gets replaced by the template. `verify_summary.py` finds every feature a summary mentions, including synonyms and codes like "pulse" or "MAP", and fails the summary if it names a feature outside the patient's top 5, says a feature raised the risk when its SHAP value lowered it (or the reverse), states a diagnosis, or brings in a reason the model never saw such as "infection". On 12 mock patients in the export format all 12 template summaries passed, and the tests show the checker catching each failure type an LLM rewrite tends to produce: an added feature, a synonym for a missing feature, a flipped direction, and a diagnostic claim. The one real failure I hit was wording, not facts: an early template said the positive features raised the risk "the most" even when the strongest features had lowered it, which a keyword check cannot see. To improve it, I would rerun on Immaculate's real export and measure DistilBART's failure rate with `--backend distilbart`, and grow the outside-reason list from real failures. I would also add a check that sentences are ordered by effect size.
